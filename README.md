# Zero Engine — Browser Edition 0.1.0

Первый рабочий прототип собственного браузерного 3D-редактора.

## Запуск
1. Распакуйте архив.
2. Откройте папку в терминале.
3. Запустите локальный сервер:
   - Python: `python -m http.server 8000`
   - затем откройте `http://localhost:8000`
4. Требуется подключение к интернету для загрузки Three.js с CDN.

Не рекомендуется открывать `index.html` напрямую через `file://`, так как браузер может блокировать ES-модули.

## Уже работает
- 3D-сцена с камерой и освещением.
- Сетка и выбор объектов мышью.
- Добавление куба, сферы, цилиндра, плоскости и источника света.
- Иерархия сцены.
- Инспектор: имя, позиция, вращение, масштаб, цвет.
- Gizmo перемещения/вращения/масштаба.
- Удаление объектов.
- Play/Stop режим (базовый).
- Сохранение и открытие сцен в JSON.
- Адаптивный интерфейс и базовый сенсорный контроллер.

## Пока отсутствует
Физика, полноценный игровой runtime, система компонентов, визуальные Blueprint-ноды, импорт моделей, текстурный редактор, экспорт автономной игры, сетевой мультиплеер и полноценная мобильная оптимизация. Это следующие этапы, а не уже реализованные возможности.

## Структура
- `index.html` — интерфейс.
- `style.css` — оформление и адаптация.
- `engine.js` — ядро редактора и 3D-сцена.
