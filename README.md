# Лето на двоих — демо визуальной новеллы

## Запуск
1. Распакуйте архив в отдельную папку.
2. Откройте `index.html` в современном браузере (Chrome, Firefox, Edge).
3. Нажмите «Далее» и начните игру.

Интернет для запуска не требуется. Шрифт подгружается из Google Fonts при наличии сети; без сети используется системный шрифт.

## Что уже реализовано
- Вступление в автобусе с монологом главного героя.
- Краткое знакомство с десятью девушками.
- Прибытие в лагерь, выбор одного из четырёх домиков и сцена с соседом.
- Карта с десятью локациями.
- Десять персонажей для общения, диалоги и очки отношений.
- Часы, смена суток и 14-дневный срок лагерной смены.
- Панель отношений, дневник, настройки музыки/громкости и автосохранение.
- Фоновая спокойная мелодия генерируется средствами Web Audio API.

## Структура
- `index.html` — интерфейс игры.
- `style.css` — оформление.
- `game.js` — логика, персонажи, события и сохранение.
- `assets/` — папка для будущих изображений и музыки.

## Важно
Это стартовый игровой прототип, а не финальная новелла. Сейчас визуальные фоны сделаны CSS-иллюстрациями, а диалоги короткие и демонстрационные. Следующий этап — добавить портреты персонажей, фоновые CG, больше ветвлений, расписания героинь, полноценные сюжетные линии и систему концовок.
